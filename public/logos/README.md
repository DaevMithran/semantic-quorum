# Company logos for Agent Town

Drop each company's official logo here (SVG preferred, or a PNG of at least 256 px), named as in
`src/town/companies.ts`:

| File | Company |
|---|---|
| `semantic-quorum.svg` | Semantic Quorum HQ |
| `agent-guild.svg` | Agent Guild (seller agents) |
| `0g.svg` | 0G Private Computer |
| `arc.svg` | Arc |
| `erc-8183.svg` | ERC-8183 Job Exchange |
| `chainlink.svg` | Chainlink |

Until a file exists, the building's sign shows the company's initial. Use the logos from each sponsor's
official brand kit and follow their usage guidelines.

To add a company: add an entry to `COMPANIES` in `src/town/companies.ts` (name, colours, logo path, a free
lot), and put its logo here. It gets a generic interior automatically.
